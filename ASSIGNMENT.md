# 📄 Handsome the Police Dog

**Course:** AMEC ____ — Web Design 1
**Due:** ____ at ____
**Points:** 15

## 🎯 Overview

In this first coding exercise, you will turn plain text about **Handsome**, Cincinnati's
first unofficial police dog, into a working HTML web page and publish it to the web.

The goal is *not* a visually designed page. HTML gives a page its structure and meaning;
CSS, which we cover later in the course, controls colors, fonts, layout, and spacing.
Your finished page will look plain, and that is exactly right.

## 🧠 What You Will Practice

- Cloning a repository and working on a branch in GitHub Desktop
- Renaming a `.txt` file as an `.html` file
- Building the basic structure of an HTML document
- Using headings (`h1`, `h2`) and paragraphs (`p`)
- Adding images with the `src` and `alt` attributes
- Previewing an HTML file in a browser
- Publishing a page with GitHub Pages and submitting a pull request

## 📋 Requirements

Build your page by renaming `handsome.txt` to `index.html` and marking up the text inside it.

- [ ] `handsome.txt` has been renamed to `index.html` and sits in the **root folder** of this repo
- [ ] The file has a complete HTML document structure: `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, and `<body>`
- [ ] The article title is marked up as an `h1`
- [ ] The two section headings — *The Policeman's Pal* and *Handsome Today* — are marked up as `h2` elements
- [ ] Every paragraph of body text is wrapped in its own `p` element
- [ ] `handsome.jpg` replaces its placeholder line in the first section
- [ ] `handsome-today.jpg` replaces its placeholder line in the "Handsome Today" section
- [ ] Both images use a correct `src` path and include meaningful `alt` text
- [ ] The copyright line at the end of the text is included on the page
- [ ] Both images load when you open the page in a browser — no broken image icons
- [ ] The page is live on GitHub Pages and the URL is in your pull request

> [!IMPORTANT]
> Rename the file — do not create a second one. When you are done there should be an
> `index.html` in the repo and no `handsome.txt`.
>
> The name `index.html` matters: GitHub Pages serves `index.html` automatically at your
> site's root URL. Any other name will give you a 404.

## 📂 Starter Files

| File / Folder | Purpose |
| --- | --- |
| `handsome.txt` | The plain text for the article. **Rename this to `index.html`** and add your markup to it. |
| `handsome.jpg` | Historical photo of Handsome. Goes in the first section. |
| `handsome-today.jpg` | Handsome on display today. Goes in the "Handsome Today" section. |
| `index.html` | **What `handsome.txt` becomes.** Your finished web page. |

Inside `handsome.txt`, two lines mark where the images belong:

```
[replace this with the image handsome.jpg]
[replace this with the image handsome-today.jpg]
```

Delete each placeholder line and put an `<img>` element in its place.
